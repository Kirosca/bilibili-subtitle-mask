# Bilibili 无字幕观影（字幕遮挡条）

> 专门为外语学习、听力训练或纯净原声观影设计的 B 站外置极简字幕遮挡条 Tampermonkey 脚本。

[![Version](https://img.shields.io/badge/version-1.5.1-blue.svg)](https://github.com/Kirosca/bilibili-subtitle-mask)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

---

## 🌟 核心特性

1. **独立外置书签手柄**：
   - 不侵入、不裁切视频画面，零重排极速跟手；
   - 随鼠标移入瞬时唤醒，移出 0.8s 呼吸渐隐；
   - 伴随外置快捷重新检测圆形雷达按钮，支持同频浮现与隐形。

2. **自适应内嵌字幕智能识别与双行/双语支持**：
   - 纯前端 Canvas 像素分析，不依赖外部 OCR 服务，零网络延迟与零隐私泄露；
   - 画面底部（58%~96%）水平边缘梯度差分算子精准捕捉台词；
   - **智能识别任意双行/双语字幕（中英/英中/日中/中日等）**：支持在弹窗/右键菜单/油猴菜单自由选择【全部遮挡】或【仅遮挡下行】；
   - **增强多色字芯与即时响应 (v1.5.1)**：全面支持高光白、醒目黄、青蓝/浅蓝、草绿等多色字芯捕获与行间断点自适应切分，切换策略 0 延迟即时重算并贴合遮挡；
   - 四重视觉防御（字芯发光色校验、纵向厚度约束 $\le 22\%$、横向居中约束 $34\% \sim 66\%$、25% 物理天花板硬截断），杜绝衣服褶皱与背景误检。

3. **双策略起播控制（新视频策略）**：
   - **持续监听直到遮挡**：新视频起播后后台静默监听，画面出现首句台词时自适应高度并自动升起遮罩锁定；
   - **默认完全关闭**：新视频起播保持关闭，不主动监听，随时按需手动唤起。

4. **四级级联记忆与智能管理**：
   - 单 P 专属记忆 > 合集/剧集记忆 > UP 主记忆 > 全局默认值（13.5%）；
   - 内置 2000 条 LRU 自动垃圾回收机制；
   - 油猴菜单一键呼出 B 站原生风格管理弹窗，支持记忆查看、重置与二次确认。

5. **透视偷看与快捷操作**：
   - 鼠标长按手柄或按下 `Alt + J`：遮罩立即呈现 50% 半透明透光偷看，松开瞬间恢复 100% 遮蔽；
   - 拖拽手柄平滑微调遮挡高度，支持滚轮微调与键盘微调。

## ⌨️ 快捷键列表

| 快捷键 | 功能说明 |
| :--- | :--- |
| **`Alt + M`** | 切换字幕遮挡条开启 / 关闭 |
| **`Alt + J`** / 长按手柄 | 50% 透光半透明看字幕（松开瞬灭） |
| **`Alt + O`** | 智能重新检测字幕高度并覆盖锁定 |
| **`Alt + 1 ~ 5`** | 预设高度档位秒切（11% ~ 19%） |
| **`Alt + ↑ / ↓`** | 精细微调高度（步进 0.5%） |

## 📦 安装方式

1. 安装浏览器脚本管理器插件（推荐 [Tampermonkey](https://www.tampermonkey.net/)）；
2. 打开脚本源文件链接，点击安装即可：
   - [bilibili-subtitle-mask.user.js](https://raw.githubusercontent.com/Kirosca/bilibili-subtitle-mask/main/bilibili-subtitle-mask.user.js)
